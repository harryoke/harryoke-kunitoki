Instruction Manual

A compact online reference to the main workflows and all 18 Doctor Tools. The application preview remains the final truth source after every repair.

Safe working model

  1. Keep the original CDG, audio and karaoke ZIP.
  2. Open the song or ZIP in CDG Doctor.
  3. Run Doctor / Full Health Check before making major changes.
  4. Use the most specific repair tool for the symptom.
  5. Preview the result visually and listen with matching audio where possible.
  6. Save a new/versioned output.

Opening material

Use Add CDG / ZIP for loose CDG files or karaoke ZIP packages. Drag-and-drop is also supported. Scan Folder can recursively discover karaoke material. When a matching audio file shares the base filename, Doctor attempts to pair it automatically.

Main workspace

  • File Library: loaded songs, duration, status and issue counts.
  • Graphics Preview: rendered CD+G screen and visual verification.
  • Waveform / Smart Navigation: seek to vocals, issues, palette events and page boundaries.
  • Visual Page Timeline: thumbnails of detected display/page regions.
  • Doctor Tools: 18 diagnostics, repair, conversion, authoring and QC pages.

Repair tools

1. Doctor / Full Health Check

Whole-file diagnostics for packet structure, palettes, graphics, timing and presentation clues. Use it first when you do not yet know what is wrong.

2. Smart Rebuild

Reconstructs damaged or unreadable lyric regions from surviving timing and graphics evidence. Best when the stream still contains enough structure to infer the damaged presentation.

3. Deep Recovery

Advanced recovery for corruption that cannot be handled by ordinary repairs. Use on a copy and verify every recovered region.

4. Page Surgery

Repairs, replaces, hides, cuts or reconstructs individual display pages or sections. Hide preserves timing; Cut is more destructive and should be used only when you understand the timing consequence.

5. Scan

Searches for known faults, suspicious commands and structural/timing anomalies.

6. Fix

Applies supported automatic or selected repairs found by Scan/Doctor.

7. Colour Doctor

Diagnoses foreground/background, palette, transparency and colour-related faults.

Edit & presentation

8. Style Converter

Analyses presentation Mode DNA and converts supported material. Smart Roll-up routes conventional page/hybrid material and Dynamic Row-Reuse material to different engines, preserves existing native vertical scroll where appropriate, and guards horizontal-scroll or split-screen/duet candidates.

9. Page Studio

Detailed page-level editing and reconstruction while retaining original timing, positioning, colours and wipe behaviour where possible.

10. Easy Editor

Visual workflow for common changes without packet-level knowledge.

11. Timing

Page, CDG and audio/graphics synchronisation tools. Hard packet insertion can alter downstream timing, so prefer supported timing operations and verify playback.

Create & author

12. Authoring Studio

Creates new CD+G text and graphics content.

13. Watermark / Batch

Adds supported logos/watermarks and applies selected operations across multiple files while preserving non-CDG ZIP members when rebuilding karaoke archives.

Professional & advanced

14. Pro / QC

Virtual QC, compatibility analysis, Palette Timeline, Pixel Inspector and reporting tools.

15. Expert Wipe

Low-level inspection/editing of wipe and highlight behaviour.

16. Expert Images

Advanced image/graphics-region controls.

17. Expert Text

Advanced text and lyric authoring controls.

18. Tools

Collection-level operations, specialist utilities and maintenance functions.

Smart Roll-up and Dynamic Row-Reuse

CD+G stores timed graphics commands, not formal lyric pages or hidden text. Some authoring systems repeatedly repaint the same physical rows. Doctor identifies this Dynamic Row-Reuse pattern by glyph shape rather than OCR, then reconstructs compatible events into a roll-up lane while preserving colour-only highlighting.

  • Uses safe packet slots instead of changing total stream length.
  • Checks packet budget before committing conversion work.
  • Can keep unsafe prefixes/sections source-authored and resume later.
  • Suppresses obsolete row-reuse erase updates from destroying rolled history.
  • Performs readability QC before accepting the preview.

Projects, reports & preferences

Projects use the .hazzcdg format for editing sessions. Versioned saves and project history reduce the risk of losing a good intermediate state. Support ZIP and HTML/JSON reports can be used for diagnostics. Preferences includes skins, appearance options and Expert Mode; expert wipe/image/text navigation becomes visible when Expert Mode is enabled.

Troubleshooting quick map

  • Unreadable lyrics: Doctor → Smart Rebuild / Deep Recovery / Style Converter depending on diagnosis.
  • Wrong colours: Colour Doctor.
  • One bad page: Page Studio or Page Surgery.
  • Want rolling lyrics: Style Converter → Smart Roll-up.
  • Audio/CDG feels offset: Timing / Audio-CDG Sync.
  • Need to inspect exact pixels/palettes: Pro / QC → Pixel Inspector / Palette Timeline.
  • Need many files processed: Watermark / Batch or collection tools.
Golden rule: If a conversion cannot be done safely, an unchanged readable section is better than a forced unreadable one.
