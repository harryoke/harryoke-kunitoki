Instruction Manual

A compact online reference to the main workflows and all 18 Doctor Tools. The application preview remains the final truth source after every repair.

New in v2.0.6: guided one-click and deeper repair

Full Health Check now leads from diagnosis through automatic repair and visual verification. Doctor first displays the error information, then offers Fix Everything Safely when high-confidence repairs are available. The original source remains untouched.

The one-click result opens on the complete page containing the first error, with Original and One-click Fix side by side. A responsive full-track slider uses cached one-second render checkpoints so pages update quickly while you search the timeline.

  1. Open the original CDG or karaoke ZIP and run Full Health Check.
  2. Read the error report and choose Fix Everything Safely.
  3. Compare Original and Fixed on the first-error page.
  4. Drag the slider through the entire track while both versions remain visible.
  5. Click Continue and choose Keep Reviewing, Happy — Save Fixed File, or Continue to Deeper Fixes.
  6. Deeper Fixes rescans the fixed working copy and starts Assisted Word Repair only for remaining visible damage.

Assisted Word Repair

Doctor can replace a damaged word or group of letters without rebuilding the whole song. It is available from the deeper fixed-copy route or directly through the dedicated Assisted Word Repair action on Doctor.

The replacement is drawn at full height in its normal base colour before singing begins, then follows the recovered original highlight/wipe timing. Doctor matches the page's colours and closest font style. Smaller, Auto Match and Larger adjust size; Move Up, Move Down and Reset Position align the baseline one pixel at a time.

Assisted repair workflow

  1. Keep the original CDG, matching audio and karaoke ZIP.
  2. Use Continue to Deeper Fixes after one-click review, or click Assisted Word Repair directly.
  3. Enter the correct word or letters.
  4. Drag a tight box around only the damaged text in the Doctor preview.
  5. Use Smaller, Auto Match or Larger if the preview needs a size adjustment.
  6. Use Move Up or Move Down to align the replacement, or Reset Position to return to the detected line.
  7. If the box is wrong, use Undo Last Word Repair / Redraw Box.
  8. Click Apply Word Fix. Doctor advances through the remaining damaged locations, then save a repaired copy.

The assisted operation changes only the selected tile region. It preserves packet count, duration, paired-audio timing, later pages and the scheduled singing wipe. If safe packet capacity is too fragmented, Doctor refuses the preview instead of drawing a split or late word.

Strict-player compatibility retained

Doctor also detects delayed repeated Memory Preset clears that can corrupt lyric pages in VLC, Karaoke Builder and OpenKJ. Every graphics command is processed sequentially even when preview drawing is throttled. The SOKC-0221 timing-preserving repair remains enabled.

Page and fullscreen performance

Ordinary page generation no longer starts Advanced Presentation Analysis automatically. Run that deeper scan explicitly from Style Converter. Maximise, restore and fullscreen refresh only the visible workspace; hidden tool previews update when opened.

Safe working model

  1. Keep the original CDG, audio and karaoke ZIP.
  2. Open the song or ZIP in CDG Doctor.
  3. Run Doctor / Full Health Check before making major changes.
  4. Use the most specific repair tool for the symptom.
  5. Preview the result visually and listen with matching audio where possible.
  6. Save a new/versioned output.

Opening material

Use Add CDG / ZIP for loose CDG files or karaoke ZIP packages. Drag-and-drop is also supported. Scan Folder can recursively discover karaoke material. When a matching audio file shares the base filename, Doctor attempts to pair it automatically.

Main workspace

  • File Library: loaded songs, duration, status and issue counts.
  • Graphics Preview: rendered CD+G screen and visual verification.
  • Waveform / Smart Navigation: seek to vocals, issues, palette events and page boundaries.
  • Visual Page Timeline: thumbnails of detected display/page regions.
  • Doctor Tools: 18 diagnostics, repair, conversion, authoring and QC pages.

Repair tools

1. Doctor / Full Health Check

Whole-file diagnostics for packet structure, palettes, graphics, timing and presentation clues. The v2.0.6 guided route reports the errors, offers one-click safe repair, opens full-track Original / Fixed comparison and can rescan the fixed working copy for deeper Assisted Word Repair. A dedicated Assisted Word Repair action also works directly from the selected finding or current timeline.

2. Smart Rebuild

Reconstructs damaged or unreadable lyric regions from surviving timing and graphics evidence. Timing DNA and Style DNA have clear enabled/off states, while the lettering controls can use installed Windows fonts with automatic or manual sizing.

3. Deep Recovery

Advanced recovery for corruption that cannot be handled by ordinary repairs. Use on a copy and verify every recovered region.

4. Page Surgery

Repairs, replaces, hides, cuts or reconstructs individual display pages or sections. Hide preserves timing; Cut is more destructive and should be used only when you understand the timing consequence.

5. Scan

Searches for known faults, suspicious commands and structural/timing anomalies.

6. Fix

Applies supported automatic or selected repairs found by Scan/Doctor.

7. Colour Doctor

Diagnoses foreground/background, palette, transparency and colour-related faults.

Edit & presentation

8. Style Converter

Analyses presentation Mode DNA and converts supported material. Smart Roll-up routes conventional page/hybrid material and Dynamic Row-Reuse material to different engines, preserves existing native vertical scroll where appropriate, and guards horizontal-scroll or split-screen/duet candidates.

9. Page Studio

Detailed page-level editing and reconstruction while retaining original timing, positioning, colours and wipe behaviour where possible. Windows font overrides and live previews are available when replacement lettering is needed.

10. Easy Editor

Visual workflow for common changes without packet-level knowledge. Choose an installed Windows font and size per text item, preview it live, or auto-fit the selected font; the same lettering is used for wrapping, wipe rendering and final CD+G output.

11. Timing

Page, CDG and audio/graphics synchronisation tools. Hard packet insertion can alter downstream timing, so prefer supported timing operations and verify playback.

Create & author

12. Authoring Studio

Creates new CD+G text and graphics content.

13. Watermark / Batch

Adds supported logos/watermarks and applies selected operations across multiple files while preserving non-CDG ZIP members when rebuilding karaoke archives.

Professional & advanced

14. Pro / QC

Virtual QC, compatibility analysis, Palette Timeline, Pixel Inspector and reporting tools.

15. Expert Wipe

Low-level inspection/editing of wipe and highlight behaviour.

16. Expert Images

Advanced image/graphics-region controls.

17. Expert Text

Advanced text and lyric authoring controls.

18. Tools

Collection-level operations, specialist utilities and maintenance functions.

Smart Roll-up and Dynamic Row-Reuse

CD+G stores timed graphics commands, not formal lyric pages or hidden text. Some authoring systems repeatedly repaint the same physical rows. Doctor identifies this Dynamic Row-Reuse pattern by glyph shape rather than OCR, then reconstructs compatible events into a roll-up lane while preserving colour-only highlighting.

  • Uses safe packet slots instead of changing total stream length.
  • Checks packet budget before committing conversion work.
  • Can keep unsafe prefixes/sections source-authored and resume later.
  • Suppresses obsolete row-reuse erase updates from destroying rolled history.
  • Performs readability QC before accepting the preview.

v2.0.0 repair safety

Doctor distinguishes missing parity, standard stored ECC, non-standard/unreliable ECC and plausible-but-unrecoverable graphics damage. Legacy files with no stored parity are not treated as mass corruption, and uncertain graphics commands are preserved for review instead of being blindly deleted.

  • Parity-less legacy media is protected from false ECC repair.
  • Non-standard ECC schemes are reported and preserved.
  • Palette-heavy animation and legal reset sequences are protected from false Critical findings.
  • Deep Recovery only attempts ECC work where meaningful stored ECC exists.

Hybrid scroll and Duet Inspector

v2.0.0 recognises Native Vertical Scroll + Dynamic Row-Reuse hybrids only when both behaviours occur in the same reset section. Style Converter preserves already-scrolling hybrids instead of re-converting them.

The Duet Inspector analyses colour roles, spatial regions, timing and singer hand-offs without OCR or invented performer names. Interactive preview overlays are non-destructive and can jump to Previous / Next hand-offs. Shared-graphics duets are protected rather than given invented role overlays.

Projects, reports & preferences

Projects use the .hazzcdg format for editing sessions. Versioned saves and project history reduce the risk of losing a good intermediate state. Support ZIP and HTML/JSON reports can be used for diagnostics. Preferences includes skins, appearance options and Expert Mode; expert wipe/image/text navigation becomes visible when Expert Mode is enabled.

Troubleshooting quick map

  • Unreadable lyrics: Doctor → Smart Rebuild / Deep Recovery / Style Converter depending on diagnosis.
  • Known damaged word or letters: Doctor → Assisted Word Repair.
  • Wrong colours: Colour Doctor.
  • One bad page: Page Studio or Page Surgery.
  • Want rolling lyrics: Style Converter → Smart Roll-up.
  • Audio/CDG feels offset: Timing / Audio-CDG Sync.
  • Need to inspect exact pixels/palettes: Pro / QC → Pixel Inspector / Palette Timeline.
  • Need many files processed: Watermark / Batch or collection tools.
Golden rule: If a conversion cannot be done safely, an unchanged readable section is better than a forced unreadable one.
