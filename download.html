v2.0.3 highlights

  • Strict sequential preview processing: every CD+G packet changes decoder state even when drawing is throttled.
  • Delayed Memory Preset propagation detection for corruption reproduced by VLC, Karaoke Builder and OpenKJ.
  • Timing-preserving five-packet safe repair for the SOKC-0221 regression case.
  • Ordinary page generation no longer launches the much deeper presentation scan automatically.
  • Optional row-reuse analysis reduced from about 149.5 seconds to 10.5 seconds on the regression track.
  • Maximise, restore and fullscreen refresh only the visible workspace.
  • Updated Complete Manual, Dummy's Guide, online help and strict-player repair guide.
  • 49 focused v2.0.3 regression tests passed.
