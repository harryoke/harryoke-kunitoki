The v2.0.5 installer uses a HazzKaraoke self-signed certificate rather than a commercial code-signing certificate, so Windows SmartScreen may still show a warning. The published SHA-256 checksums let you verify the exact release files.

Which download should I choose?

  • Windows Installer — recommended: easiest option for almost everyone. Download, run Setup and start using Doctor.
