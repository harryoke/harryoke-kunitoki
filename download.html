About the Windows security warning

The v1.8.0 binaries are Authenticode-signed with a HazzKaraoke self-signed certificate. Because it does not chain to a publicly trusted certificate authority, Windows SmartScreen or an Unknown Publisher warning may still appear on another PC. The published SHA-256 checksums let you verify the exact files distributed here.

Verify your download

GitHub hosts the Windows checksum manifest alongside the release files. Compare the SHA-256 of your downloaded file with the published value if you want to verify it before running.

Which download should I choose?

  • Windows Installer — recommended: easiest option for almost everyone. Download, run Setup and start using Doctor.
