Which download should I choose?

  • Windows Installer — recommended: easiest option for almost everyone. No compiling required.
  • Portable ZIP: useful if you do not want to install the program. Extract it first; do not run the EXE from inside the ZIP.
  • Source / Build ZIP: only for developers or people who want to inspect/build the project themselves.

What changed in v1.7.1?

  • Correct four-line roll-up geometry.
  • Smart Hybrid safety behaviour retained when packet budget is insufficient.
  • 158 regression tests passed.
