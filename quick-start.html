Dummy's Guide

You do not need to understand CD+G packets to start. Find the problem that sounds like yours and follow the short route below.

Start here every time

  1. Make sure you still have the original CDG/ZIP.
  2. Open the song with Add CDG / ZIP or drag it into the program.
  3. Press Doctor / Full Health Check.
  4. Play or seek to the bad part in the graphics preview.
  5. Use the matching recipe below.
  6. Preview the result before saving.
  7. Save a new version. Do not replace your only original.

My lyrics are unreadable or corrupted

  1. Run Doctor / Full Health Check.
  2. If Doctor reports recoverable damage, try Smart Rebuild.
  3. For deeper corruption, use Deep Recovery.
  4. If the problem appeared after a presentation conversion, go back to the original unconverted CDG and use Style Converter again.
  5. Check the repaired section visually before saving.

The lyric colours are wrong

  1. Seek to the bad section.
  2. Open Colour Doctor.
  3. Inspect palette/foreground/background problems.
  4. Apply the smallest suitable repair.
  5. Play through the colour change and highlight before saving.

Only one page is bad

Use Page Studio when you want to repair or reconstruct a particular lyric page. Use Page Surgery when you need to hide, cut, replace or structurally repair a display section.

Tip: hiding a bad display is normally safer than cutting packets unless you specifically need the timing removed.

I want scrolling / roll-up lyrics

  1. Open Style Converter.
  2. Use Smart Roll-up / Auto first.
  3. Let Doctor analyse the presentation style.
  4. If it finds Dynamic Row-Reuse, it will use the dedicated row-reuse engine rather than treating the whole song like simple pages.
  5. If part of the song cannot be converted safely, Doctor may leave it original and continue later. That is normal safety behaviour.
  6. Watch several transitions before saving.

I have a duet / split-screen track

  1. Open Style Converter and use Duet Inspector.
  2. Check the detected Colour Roles and singer hand-offs.
  3. Use Previous / Next hand-off to inspect role changes.
  4. If Doctor reports shared graphics or an unsafe duet structure, preserve it rather than forcing a roll-up conversion.
  5. The preview overlays are guides only; they do not alter the CD+G pixels.

The audio and lyrics are out of sync

  1. Make sure the correct matching audio is loaded.
  2. Open Timing / Audio-CDG Sync.
  3. Make a small adjustment.
  4. Check the beginning, middle and end of the song — not just one line.
  5. Save a new version once the whole song stays aligned.

I want to add text, graphics or a logo

Use Authoring Studio for new CD+G content. Use Watermark / Batch when applying supported branding operations across multiple tracks.

I don't know which button to use

  • Don't know what's wrong: Doctor.
  • Unreadable lyrics: Smart Rebuild.
  • Seriously damaged: Deep Recovery.
  • One page: Page Studio.
  • Remove/repair a page section: Page Surgery.
  • Colours: Colour Doctor.
  • Scrolling/page style: Style Converter.
  • General visual edit: Easy Editor.
  • Sync: Timing.
  • Create new content: Authoring Studio.
  • Many files: Watermark / Batch.
  • Final quality check: Pro / QC.
Best beginner rule: Doctor first, preview everything, save a new version.
